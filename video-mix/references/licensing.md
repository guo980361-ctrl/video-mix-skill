# 商用授权与合规注意事项

混剪视频要发布到平台时，以下几件事必须先确认。**免费 ≠ 无限制商用**。

## 各环节授权现状

| 环节 | 本 skill 默认方案 | 商用状态 |
|---|---|---|
| 文生图 | Pollinations（flux / zimage / sana 模型） | ⚠️ 见下 |
| 图生视频 | LTX-Video distilled | ⚠️ 见下 |
| 对口型 | Wav2Lip | ⚠️ 见下 |
| 配音 | Microsoft Edge TTS | ⚠️ 见下 |
| 后期 | ffmpeg | ✅ 无限制 |

## 逐项说明

### Pollinations 生成的图片

- 免费层输出**带 `pollinations.ai` 水印**（实测 `nologo=true` 无效）
- 平台定位为"开源社区 + 捐赠支持"，**API 输出用于商业用途的授权条款不明确**
- 建议：商业项目改用本地 FLUX / SDXL（Apache 2.0 / MIT），或购买 Pollinations 的 API 商业版
- **替代方案**：本地部署 FLUX.1-schnell（Apache 2.0），商用无忧

### LTX-Video

- 官方仓库为 **LTX 社区许可**：年营收低于 1000 万美元免费
- 达标的商业公司需向 Lightricks 申请许可
- 个人创作者、小团队、创业早期通常在免费范围内，但**收入超过门槛前要主动确认**

### Wav2Lip / MuseTalk

- MuseTalk 是 **MIT**，商用友好
- Wav2Lip 原始仓库标明**个人非商业用途**为主，商业使用需自行评估
- 建议商业项目优先选 **LatentSync（Apache 2.0）** 或 **MuseTalk（MIT）**

### Microsoft Edge TTS

- 微软官方未将 Edge TTS 作为商用 API 提供，**条款上属于非授权访问**
- 平台上有大量同类工具（剪映免费音色、讯飞新用户额度）在做商用授权
- 建议：商业项目改用
  - **讯飞配音**：新用户免费额度，商用授权规则清晰
  - **CosyVoice**（阿里开源，MIT）：本地部署，情感与音质都够商用
  - **剪映网页版**：基础音色免费，配音+字幕+配乐一体化

### 肖像权与人物素材

给图片做对口型，用的是**别人的脸**时：

- 必须获得肖像权人授权
- 不得用于伪造该人物未作出的言论或行为
- 不得用于政治类、新闻类等敏感场景的虚构内容
- 不得涉及逝者形象（除非获得合法授权）

平台审核对 AI 生成内容的标识要求也在收紧，发布时按平台规则勾选"AI 生成"声明。

## 发布前检查清单

- [ ] 所有素材的商用授权已确认（逐项对照上表）
- [ ] 肖像权授权齐备（涉及真人脸时）
- [ ] 音乐 BGM 来自有授权的曲库（不要随手用短视频平台的热门音乐）
- [ ] 已按平台要求标注 AI 生成内容
- [ ] 内容不含虚构的真人言论、事件或产品功效宣称
- [ ] 平台特有规则已核对（抖音/视频号/B站/小红书的 AI 内容标识要求不同）

## 一句话建议

**个人创作 / 自媒体测试**：本 skill 的免费组合完全够用，注意加水印和平台 AI 标识即可。

**商业项目 / 客户交付**：把生图迁到本地 FLUX（Apache 2.0）、TTS 迁到 CosyVoice（MIT）或讯飞、对口型迁到 LatentSync 或 MuseTalk、LTX 确认社区许可门槛——只需替换 `scripts/` 里对应的单个 backend 函数，混剪合成部分完全不用动。
